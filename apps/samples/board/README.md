# Board (sample)

A team task board that needs sign-in (`<bindle-gate>`): boards and cards in storage the person chooses, live updates
between open boards through a personal event bus, "Assigned to you" app messages, and an organization context through
member certificates (`acquireMemberCertificate`). Host `board.example` in the multi-provider simulation
(tests/sim/parts/board.mjs). Sample-only, MIT, not published.
