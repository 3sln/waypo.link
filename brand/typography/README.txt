Waypo.link service typography

The hosted wordmark uses Manrope Semibold (600). The social card uses Manrope
Bold (700) headlines and Medium (500) supporting text. The green/coral route
symbol and icon-only assets are unchanged. The open-source Waypo branding is
separate and is not regenerated by these scripts.

The unmodified source font, its OFL license and FONTLOG are retained here.
provenance.json records the exact upstream Google Fonts revision and file hashes.
Public SVG assets contain glyph outlines, not SVG text or external font URLs.
The source TTF is outside site/assets and is not published by the docs build.

Regenerate the artwork using optional developer tools (no runtime dependency):

  python3 -m venv .artifacts/typography/tools
  .artifacts/typography/tools/bin/pip install fonttools==4.60.1
  .artifacts/typography/tools/bin/python brand/build-typography.py

Install Playwright1.64.0 as a local optional build tool or set PLAYWRIGHT_MODULE
to the module URL of an existing installation, then render the outlined card:

  node brand/build-typography.mjs
  node hosted/waypo/build-branding.mjs
  npm run build:docs
  npm run check:docs

hosted/waypo/build-branding.mjs takes the hosted wordmark and social card from
site/assets. Unchanged icon-only user/admin assets continue to use the installed
reference package's distinct Waypo.link family; no vendor pin is modified.
